# FTTx-бот в браузере: установка (≈10 минут)

Бот живёт во вкладке Qlik в Chrome:
- После каждой перезагрузки WFM (проверка раз в 5 минут, с 8:00 до 22:59) он кладёт свежий `data.json` в GitHub.
- По кнопке «🔄 Обновить сейчас» под сводкой в Telegram (или по команде `/update`) он сразу собирает последние данные.

Коммит `data.json` запускает Action «FTTx — сводка в Telegram», и сводка приходит в чат.

## 1. Tampermonkey
1. Установите расширение **Tampermonkey** из Chrome Web Store.
2. Откройте `chrome://extensions`. Включите **Режим разработчика** (вверху справа) **или** в карточке Tampermonkey → «Сведения» включите **«Разрешить пользовательские скрипты»**. Без этого Chrome не запускает скрипты.

## 2. Токен GitHub
1. Откройте https://github.com/settings/personal-access-tokens/new
2. **Token name:** `fttx-bot`. **Expiration:** на ваше усмотрение (например, 1 год).
3. **Repository access:** *Only select repositories* → `fttx-dashboard`.
4. **Permissions → Repository permissions → Contents:** *Read and write*.
5. Нажмите **Generate token** и скопируйте токен (он показывается один раз).

## 3. Установка скрипта
Откройте https://raw.githubusercontent.com/dinarazaiko/fttx-dashboard/main/fttx-bot.user.js — Tampermonkey предложит установить скрипт, нажмите **Установить**.

## 4. Настройки
1. Откройте любую страницу Qlik `https://qtest/…` (например, лист WFM).
2. Нажмите значок Tampermonkey → **«FTTx-бот: настройки»** и введите по очереди:
   - токен GitHub из шага 2;
   - токен Telegram-бота — тот же, что в секрете `TELEGRAM_BOT_TOKEN` (его выдаёт @BotFather);
   - ID чатов — как в секрете `TELEGRAM_CHAT_ID`.
3. Внизу справа появится чёрная плашка «FTTx-бот · …». Если на неё нажать, откроется журнал.

## 5. Проверка
Значок Tampermonkey → **«FTTx-бот: обновить сейчас»**. Через 1–2 минуты в GitHub появится коммит «Данные на … (по запросу из Telegram)», а следом в Telegram придёт сводка с кнопкой. Нажмите кнопку — через минуту бот ответит «⏳ Запрос принят…», а потом придёт новая сводка.

## 6. После проверки
Выключите задачу Claude «Обновление сайта FTTx из Qlik» (переключатель «Активно»): иначе данные будут обновляться дважды.

## Условия работы
- Ноутбук включён и не спит, в Chrome открыта хотя бы одна вкладка `https://qtest/…`, и вы вошли в Qlik.
- Если открыто несколько вкладок Qlik, бот работает только в одной из них.
- Токены хранятся только в Tampermonkey на этом ноутбуке.
